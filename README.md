# Stimmwerk

Personal voice training web app: hold a pitch, hit notes, sing melodies, and see live if you must sing higher or lower.

See [PLAN.md](PLAN.md) for the decisions and milestones.

## Development

```sh
npm install
npm run dev      # http://localhost:5173 (microphone works on localhost)
npm test         # Vitest
npm run lint     # oxlint
npm run build    # type check and production build
```
